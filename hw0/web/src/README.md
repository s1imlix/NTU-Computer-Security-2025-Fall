# WEB HW0

## Goal

目標是取得 remote server 上的 `FLAG` 環境變數。

Flag format: `flag{...}`

## Deployment

```bash
docker compose up -d
```

若建置成功，你要可以在 `http://127.0.0.1:1337` 看到跑起來的服務。
